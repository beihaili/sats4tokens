Who runs this

Sats4Tokens is the bitcoin checkout of the BHBTC relay, an AI API relay (its regular console, with an account and bitcoin top-ups, is btc.bhbtc.xyz). The code is open source.

  • We never learn who you are. No account, no email. A Cashu mint can't link ecash to the wallet that paid it. Like any AI API, we and the model provider see your prompts, so keep identifying details out of them (and use Tor if your IP matters).
  • Every payment counts exactly once, even if our server crashes mid-payment (how). Reopening your key page shows the same key, never a second charge.
  • For bots and agents: buy, pay and fetch the key over plain HTTP, see the API.
