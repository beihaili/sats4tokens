How to sign it in your wallet
  • Sparrow: Tools → Sign/Verify Message → pick the address, paste the message, Sign. Works with hardware wallets connected to Sparrow.
  • Electrum: Addresses tab → right-click the address → Sign/verify message.
  • Bitcoin Core: signmessage "address" "message" (legacy 1… addresses only).
  • Taproot (bc1p…): needs a wallet that signs BIP-322 messages.
Copy the message exactly: one line, no extra spaces. The signature is a line of base64.
