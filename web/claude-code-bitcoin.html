Questions

How is it 60% cheaper?

We buy capacity from several upstream providers and route each call to one that works, so we pay wholesale instead of list price. The price comparison on the shop page is updated with the model makers' prices and ppq.ai's, with the date checked.

Do I need an account or an email?

No. Pay, get the key, that's it. The /pay/… page is your receipt — bookmark it, because it is the only way back to the key.

How do I pay?

Lightning (scan the invoice with any wallet) or a Cashu token (paste it, or scan its QR). USDT/USDC on Tron, Base, BSC or Solana is available on the checkout page too.

What if a payment doesn't produce a key?

The page says so and retries by itself; it never charges twice. If it still doesn't, DM @sats4tokens or open an issue with the order link (keep it private).

Which models can I use?

All of them — the full list with live prices is on the shop page. claude-opus-4-8 is a good default for Claude Code; deepseek-flash and gemini-3.1-flash-lite are the cheap workhorses for scripts and agents.

Sats4Tokens is the bitcoin checkout of the BHBTC relay. The code is open source — payments settle exactly once, and no account or email is stored.
